# ZSPM — nieoficjalnie

Statyczna strona startowa uczniów ZSPM. Nie wymaga instalacji zależności ani procesu budowania.

## Struktura

```text
.
├── index.html             # struktura i treść strony
├── assets/
│   ├── styles/main.css    # wszystkie style
│   ├── images/            # obrazy i grafiki projektu
│   └── scripts/           # przyszłe skrypty JavaScript
└── README.md
```

## Uruchomienie

Otwórz `index.html` w przeglądarce albo uruchom w katalogu projektu:

```sh
python3 -m http.server 8000
```

Następnie przejdź do `http://localhost:8000`.
